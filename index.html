How the current workspace works

The owner imports campaign rules and authorized media, processes videos locally using AutoClip and Ollama, reviews finished clips, and prepares approved publishing packages. Campaign eligibility and publication approvals remain required. Submission and payout records need actual supporting evidence.

TikTok connection

Official Login Kit is used to authorize and verify the dedicated account. Basic identity permission provides an account identifier and display name; optional approved profile permission provides the username. Connection is incomplete until the owner authorizes it and the authenticated API identity check succeeds. Login Kit identity permission is not publishing permission.

Private application, separate public documents

This site provides information only. It contains no dashboard, login form, database connection, media, credentials or OAuth callback. Local AI processing and private storage remain on the operator's controlled device. Automated TikTok posting is disabled and unverified.
